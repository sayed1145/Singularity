# 奇点 · Singularity v6.1 — 欧雷利亚远征（战役与贴图修复）

适用于 **Mindustry v8 / v160.5** 的 Java 模组。v6.1 保留 v5「奇点 × 以太泰坦矩阵」融合内容，并将欧雷利亚重做为可从零正常游玩的独立行星：专属核心、专属玩家机体、程序化扇区、完整地形/矿物/墙体贴图、低亮度专属动画、行星科技根、资源链与不依赖普通工厂堆叠的野外共振玩法。所有内容仍注册在单一、安全的 `blackhole-` 命名空间。

## 全新原创泰坦：星铠·圣盾

**星铠·圣盾（Astral Aegis）** 是本次新制作的白色重甲泰坦，风格是干净的白、银、青蓝与金色机甲轮廓，不采用黑洞机甲设计。

- 56,000 生命 / 42 护甲 / **真正双足**超重型机甲。采用 `MechUnit` 两腿步态，不再使用 `LegsUnit` 多足骨架，因此轮廓不会被读成蜘蛛。
- 白等离子重轨枪：蓄能后贯穿多目标。
- 双肩追踪导弹舱：交替齐射。
- 棱镜护甲：大范围六边形护盾，并维修附近友军。
- **独立手绘动画层**：分层装甲、发光面罩、头冠、两侧折叠翼、旋转光环、武器热量联动。
- 所有额外动画都是视口剔除后的少量贴图四边形；不使用逐帧粒子雨或全屏后处理。

星铠·圣盾是巨像装配台的**第三个计划**，位于苍盾泰坦之后的科技节点；生产同时需要以太合金、信号核心和奇点核心，因此不能绕开原模组的生产链。

## v6.1：新行星「欧雷利亚」与从零远征战役

欧雷利亚不是把几座炮塔放进旧科技树的内容包。它有自己的三阶网格星球、可直接登陆的起始扇区、程序化地图生成、波次入口、相邻扇区推进规则和独立科技树根。每张地图都会**直接放置欧雷利亚核心**（不再错误调用原版 `coreShard` 起始蓝图），核心生成可玩家控制的原创「流明机体」，并分配铜、铅、硅作为首批建材。起点旁必定有可开采的流明矿，地图还会生成 4 处天然共振床与两处波次入口；生成器在运行时会验证核心、矿物、节点与入口，避免出现不可开局的随机地形。

### 独立资源链

| 阶段 | 资源 / 建筑 | 作用 |
|---|---|---|
| 从零起步 | 流明机体、流明提取器、极光光伏板 | 由原创核心与首批铜/铅启动；先开采附近流明矿，再以专属光伏板供电。 |
| 野外目标 | 裂隙锚 → 共振碎片 | 裂隙锚**只能**建在天然共振床；通电并清除半径内敌军后，持续稳定裂隙并产出碎片。 |
| 空间编队 | 三座裂隙锚 + 谐振中继器 → 协律核心 | 中继器扫描半径内的稳定锚。至少 3 座同时成立才会产出协律核心；这不是传送带/配方可以替代的条件。 |
| 制造 | 棱晶压机、棱晶共鸣器 → 棱晶合金 | 只使用欧雷利亚早期资源，不要求先从塞普罗或厄瑞克尔带来原料。 |
| 单位线 | 欧雷利亚制造厂 → 微光 / 极光守卫 | 使用棱晶合金与野外网络产出的协律核心。 |
| 异星路线 | 塞普罗/厄瑞克尔配给终端与协律核心配给器 | 两颗原版星球使用各自的后期材料分配欧雷利亚资源，也能正常建设欧雷利亚制造厂和单位。 |

### 新玩法：防御式共振网络

这是 v6 的核心，而不是“矿物 → 工厂 → 炮塔”的普通变种：玩家必须离开核心，在波次和敌军压力下夺取遥远的天然节点、供电、部署裂隙锚并守到稳定。敌军进入防区会倒退稳定度（不会一击抹掉成果）；随后玩家还要在一台中继器的 230 世界单位范围内布置 **3 座**已稳定锚，形成空间上的三角谐振。只有这一阵型才能获得协律核心并解锁高阶制造、单位与防御。

v6 新增 4 种行星资源、2 种飞行单位、欧雷利亚核心、2 个野外网络建筑、2 个加工建筑、制造厂和 2 座防御塔，共 12+ 项可研究内容；其研究节点均从欧雷利亚独立根分支展开。

## 生产链与科技树融合

1. 原生主线：相位织物 → 引力压机 → 简并物质 → 霍金冷凝器 → 霍金尘埃 → **约束棱镜锻炉** → 奇点核心。
2. 单位线：视界装配厂 / 奇点船坞 → 堡垒号 → **以太压铸机**。
3. 融合材料：以太压铸机额外消耗简并物质；信号编码机额外消耗霍金尘埃。
4. 泰坦线：信号核心 → 战术控制器 → 巨像装配台 → 苍盾泰坦 → 炽霄泰坦 / 星铠·圣盾。
5. 塞普罗和厄瑞克尔均有完整的材料与装配路线；新增炮塔也拥有研究节点。

## 工厂黑洞与光污染：已彻底移除

原“奇点锻炉”曾在每台工厂上绘制黑洞、注册屏幕引力透镜并产生强亮光；大规模摆放时可能造成刺眼画面和性能下降。

v5 已将其重做为 **约束棱镜锻炉**：

- **不再生成黑洞**，不调用 `BlackHoleRenderer`，不注册屏幕扭曲。
- **无游戏光源**：`lightRadius = 0`，不会形成光污染。
- 新手绘白蓝棱镜反应堆贴图，替换旧黑洞贴图。
- 仅有两张低亮度动画贴图；全局每帧最多 18 座锻炉播放额外动画。
- 超过预算或处于镜头外的锻炉只显示静态本体，因此大量铺设不会累积特效/DrawCall。

黑洞武器、事件视界炮和战斗弹体的机制不受该“工厂视觉”改动影响。

## 安装

将根目录的 **`Singularity.jar`** 复制到 Mindustry 的 `mods` 文件夹，重启游戏并启用。

- Android：`Android/data/io.anuke.mindustry/files/mods/`
- PC：游戏内「模组 → 打开文件夹」进入的 `mods` 目录。

如已单独安装“六芒军械库”，建议停用它，以免获得两套重复玩法内容；v5 已包含其完整融合内容。

> v4.1 已按要求彻底移除“视界无人机”。若旧存档中仍存在该单位，建议先让旧实体消失或开启新存档后更新。

## 源码、生成与验证

- `tools/gen_v5_astra_assets.py`：重新生成星铠·圣盾、棱镜锻炉及全部 v5 手绘贴图。
- `tools/build-release.sh`：生成桌面 `.class` + Android `classes.dex` 的发布 jar。
- `tools/gen_v6_aurelia_assets.py`：可重复生成欧雷利亚的地表变体、矿物、墙体、核心、起始机体、所有建筑、武器层和动画发光层；不依赖原版占位贴图。
- `tools/validate_v5.py`：回归检查已完成的融合内容、白色泰坦贴图与安全锻炉配置。
- `tools/validate_v6.py`：逐项检查双足星铠、专属核心/玩家机体、全部地形变体与机器贴图、零起步生成器、三锚网络、塞普罗/厄瑞克尔配给路线、本地化和 jar 完整性。

构建依赖 JDK 17+、Mindustry v160.5 `Mindustry.jar` 和 R8/D8。示例：

```bash
JAVA_HOME=/path/to/jdk17 \
MINDUSTRY_JAR=/path/to/Mindustry.jar \
R8_JAR=/path/to/r8.jar \
./tools/build-release.sh
python3 tools/validate_v5.py
python3 tools/validate_v6.py
```
