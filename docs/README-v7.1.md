# 奇点 · Singularity v7.1 — 全 3D 欧雷利亚

适用于 **Mindustry v8 / v160.5**（已在官方 v160.5 headless 服务器上实测通过）的 Java 模组，桌面端与安卓端通用。命名空间仍是 `blackhole-`，与 v7.0 存档兼容。

v7.1 是一次「欧雷利亚彻底独立」的更新：

- **欧雷利亚不再使用任何原版内容**：物品、液体、状态、地形、运输、管道、发电、生产、制造、防御、仓储、单位（陆 / 空 / 海）与炮塔全部自研；粒子特效全部自研（含原版硬编码在核心 / 修复器 / 护盾里的特效，都已替换）；逻辑块复用原版逻辑类，但用欧雷利亚材料建造。
- **科技树修复**：不再近乎免费（每个节点按其 `researchRequirements()` 标准成本），也不再出现铜或任何原版物品。
- **黑洞重做**：删掉整屏透镜 pass（v7.0 最贵、且在 GLES 上易花屏），改为**局部透镜**——只把黑洞周围一小块屏幕拷进纹理并做爱因斯坦环弯曲，开销与黑洞面积成正比；渲染几何回到 v6.1 的表现并加上**按屏幕大小分级**的 LOD（小洞每帧几十个四边形，不再每帧算数千个顶点）。
- **战术控制器删除**；**苍盾 / 炽霄泰坦改为真 3D 步行单位**（自带步态、扇区防交叉 IK 腿、自研脚步特效与武器焰口，不再用原版腿和原版脚印特效）。
- **炮塔 / 载具武器对齐**：吸积炮双管、参考系炮、能层号、堡垒号副炮、金辉壁垒、潮汐守望者等所有多管武器现在都是从各自画出的炮管里发射（`MuzzlePattern` + `barrelSpread`），弹道终点仍精确命中瞄准点。
- **引力压机重做**：朴素的液压冲压机（床台 + 立柱 + 横梁液压缸 + 冲头钣金裙 + 落料托盘 + 冲击紫光），不再有游离斜杆和悬空方块。
- **欧雷利亚核心修复**：落地不再出现 “oh no” 缺失贴图；单位上限改为 `unitCapVariable`（核心提供 18，可再建核心增加——v7.0 把上限固定在 0，什么单位都造不出来）；起始物资是流明矿 400 / 金辉矿 80，不再注入铜。
- **新增 3D**：两层式新能层号（双管炮塔 + 旋转核心环）；欧雷利亚陆海单位（碎片漫游者、金辉壁垒、潮汐快艇、潮汐守望者）与新建筑（流明燃烧机、潮汐涡轮、淤砂窑、等离子混合器、潮汐泵、流明电池、流明修复器等）。

## 1. 黑洞：局部透镜 + LOD（不再歪、不再消失、开销大幅下降）

- **渲染**（`BlackHoleRenderer`，v6.1 表现 + v7.1 LOD）：吸积盘（双面 + 侧面厚度）、头顶 / 底部爱因斯坦弧、光子环、事件视界黑球。细分段数按屏幕上黑洞大小自适应（16–64 段、4–10 环），小的飞行黑洞每帧只需几十个四边形。
- **扭曲**（`BHShaders`，局部透镜）：全屏帧缓冲透镜已删除。每个黑洞用 `glCopyTexSubImage2D` 只拷贝周围一小块（半径 5× 视界）屏幕，再用一个四边形施加密圈弯曲，边缘渐隐无缝。成本与透镜面积成正比，屏幕外零开销；平台无关、永不越界 uniform。
- 若客户端着色器不可用，自动退化为无扭曲模式（几何渲染仍完整）。

## 2. 欧雷利亚：零原版内容

服务器实测（v160.5 headless）：

- 欧雷利亚上显示的原版内容：**0**（物品、方块、液体、单位、状态全部校验）。
- 科技树 56 个节点：原版节点 0、原版物品成本 0；非资源节点全部有标准研究成本（合计约 17 万资源）。
- 起始扇区（288×288）：原版地形格 0、原版矿格 0；核心初始物资为流明矿 400 + 金辉矿 80。
- 全部 40 个科技树方块在欧雷利亚环境可建造；波浪只使用欧雷利亚单位（碎片漫游者 / 微光 / 金辉壁垒 / 极光守卫，威胁 > 0.3 时编入星穹拘束者）。
- 单位上限：`unitCapVariable=true`，核心修正 +18，`Units.getCap = 18`，可正常建造单位。

## 3. 单位（骨骼动画）

- 飞行器按真实速度 / 转向俯仰、侧倾、悬浮起伏，带引擎尾焰；坦克有履带滚动、炮塔转动与后坐。
- 泰坦为 `Walker3D`：6 足（苍盾）/ 4 足（炽霄）自带步态，落地带碾压伤害与自研尘土特效；每只脚被钳制在各自 hip 的扇区内，膝盖走 hip–脚的竖直 IK 平面，**任何姿态下腿都不会交叉**（构建时随机 40 万对抗姿态，0 交叉、0 拉伸）。
- 远景与超预算时自动退化为烘焙 LOD 贴图。

## 4. 星穹拘束者（改为普通单位）

三臂模型保留，但 v7.1 使其成为普通重型炮艇：不再吸收弹丸 / 擒拿抛掷 / 收容敌人（对应特效与「拘束」状态已删除），从机爪发射穿透流明长矛。数值：8200 生命、15 护甲。

## 5. 删除

- **星铠·圣盾**（v7.0 删除，保持删除）。
- **战术控制器**（v7.1 删除）：两座 `titan-director-s/e` 及其模型、科技节点、本地化全部移除；泰坦线改为 信号核心 → 巨像装配台。

## 6. 兼容性引入的例外

- 欧雷利亚科技树不含任何原版节点，但为了向塞普罗 / 厄瑞克尔开放欧雷利亚单位，另在**那两个星球**的树上挂了「配给终端 / 协律配给器」分支（使用当地材料），并把流明矿、共振碎片、棱镜合金、协律核心、欧雷利亚制造厂与 8 个欧雷利亚单位设为三星球可见。
- 玩家重生闪光、单位 payload 落地火花仍使用原版特效（原版静态方法内写死，模组无法替换）。

## 构建与测试

```bash
tools/setup_env.sh   # 下载 JDK17、官方 v160.5 Mindustry.jar / server-release.jar、r8、android.jar，并克隆官方源码
./build.sh           # 编译 → 手臂/腿防重叠测试 → 烘焙全部 3D 模型与欧雷利亚图块 → 桌面 jar → D8 → dist/Singularity-v7.1.0.jar
./test_server.sh     # 官方 headless 服务器：隔离核查、科技树、地形、单位、波浪、制造厂/船坞、存档读档
```

离线预览（驱动游戏内真实绘制代码，软件光栅化输出 PNG）：

```bash
J=$(ls -d ~/.cache/vendor/jdk-17*)
$J/bin/java -Djava.awt.headless=true -cp build/classes:build/tools:$HOME/.cache/vendor/Mindustry.jar \
  preview.Preview assets/sprites out units|turrets|blocks 24 3
```

旧版说明保存在 `docs/`。
