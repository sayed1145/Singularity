## 二、后勤网络（核心重做）

原来的货运站直接继承原版 `UnitCargoLoader`，在本模组的星球规则下无人机建出来就卡死：它是 `BuildingTetherc`，一旦脱离母体就会被原版 `BuildingTetherComp.update()` 直接 `unitDespawn`，再加上原版只认「站 → 台」一条单向链路，所以表现就是「无人机不动、什么都不运」。

8.1 把它整个换成一套自有的网络（`src/blackhole/LogixParts.java` + `src/blackhole/AureliaLogix.java`）。

### 2.1 节点角色（参考 Factorio 物流网络）

网络里每个方块实现 `LogiNode`，声明一个角色：

| 角色 | 方块 | 行为 |
|------|------|------|
| 0 主动供给 | 流明供给站 | 手里有货就往外推，优先被清空 |
| 1 被动供给 | 核心 / 一般容器 | 只有别人要才会被取 |
| 2 需求 | 流明货运台 | 指定一种物品，持续请求 |
| 3 仓储 | 流明后勤仓（300 容量） | 溢出货物的归宿，取货时优先级最高 |
| 4 缓冲 | 流明缓冲站（2×2，200 容量） | 既请求又供给的中转站，带防循环判定 |

### 2.2 调度

流明超级货运站（原货运站，3×3）是网络中枢：

* 每 24 刻（有电时）扫描 `hub.range` 内的全部节点，建立请求表；
* 请求按 **饥饿度**（缺口 / 容量）加角色权重排序，不是原版的「先到先得」，所以小请求不会把大缺口饿死；
* 取货源按惩罚值选最近最合适的一个：`仓储 0 / 中枢 120 / 缓冲 180 / 被动供给 240`，再加上实际距离；
* **预约制**：已经在路上的货会从请求缺口里扣掉，不会出现三架机同时去送同一份货；
* 自己库存溢出时反向把货推进仓储，仓库不会空转；
* 中枢会 **收养** 范围内无主的流明运输机（玩家自己造的也算），给它派活，所以机队可以手动扩编。

无人机控制器 `PorterAI`：取货 → 送货 → 60 秒超时自动卸货回收，掉线找不到中枢时会在 900 单位范围内每秒重新找一次，不会变成空中雕像。

实测（`./logitest.sh`）：

```
hub: built 1 drone in 960 ticks, tethered=true, controller=PorterAI
haul after 25s: nodes seen=3, drone moved 20, supply 120->60, pad 0->60, dispatched 1
surplus: hub holds 0, vault holds 90 aurite, dispatched 2
hauler adoption: home=lumen-cargo-station at 153,140, hub drone list=2
```

### 2.3 新的液体运输方式

**流明液体中继**（2×2）：不铺管，把液体以 22 格为半径「投送」给其它中继 / 容器，每刻 9 单位，最多 6 条链路，带上限不会无限串联。实测：相隔 16 格、中间**没有任何管道**，目标中继 1 刻后收到 9 单位。

另外 **潮汐补给舰**（naval）可以带着液体弹药在水面支援，属于液体线的机动补充。

### 2.4 溢流门 / 反向溢流门

按原版 `OverflowGate` 机制实现（`invert` 控制正反），只换成自有 3D 模型：正门把堵住的货分流到旁路，反门只在旁路堵死时才走正前方。1×1，造价 `流明 14 + 棱镜玻璃 8/10`。

## 六、战役地形重做

旧生成器被「勺子形」人工痕迹毁掉：大圆形湖 + 直线道路 + 等距刷怪环。8.1 按论文流程重写（见第八节）：

1. **域扭曲（domain warping）的 fBm + 脊状噪声** 生成高程：扭曲让等高线不再是圆，脊状噪声给出真正的山脉走向。
2. **液滴水力侵蚀**（带动量，不是贪心最低邻居）：冲出沟壑与冲积扇。
3. **D8 汇流累积**：河流只在汇水量足够的地方出现，自然地从高处流进湖里；湖泊是洼地积水，不是画上去的圆。
4. **细胞自动机**整理岩层，使山体成块、边缘破碎，而不是噪声麻点。
5. **气候分区**（高度 × 湿度 × 纬度）决定地表种类，所以同一张图里有连片的生态区而不是花斑。
6. **蠕虫算法矿脉**：矿顺着岩层走向延伸，而不是圆斑。
7. **通路**：所有连接（包括连通性兜底）现在都沿噪声场**蜿蜒**前进，8.0 遗留的直线「尺子路」已经消失。

刷怪口：沿核心外 30%–44% 的公平带布置，距离随地形变化但**绝不会贴脸**；困难图最多 5 个。

实测（`./maptest.sh` 全量 + `test_server.sh` 抽样）：32/32 扇区生成通过，尺寸 272–348，墙体 20–24%，地形种类 14，刷怪口 ≤5，地形指纹互不相同。渲染图见 `mapview-a/b/c.png`、`v81-new-content.png` 底部。
