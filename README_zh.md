## 下载

- **二进制（推荐）**：[`Singularity-8.8-Release.jar`](https://github.com/sayed1145/Singularity/releases/tag/8.8-Release)
  —— 挂在 Release 上。**桌面和安卓通用同一个 JAR**（里面既有给桌面 JVM 用的 Java `.class`，
  也有给 Android/ART 用的 `classes.dex`）。
- **源码**：本仓库，或 GitHub 自动生成的源码打包。

### 安装

1. 下载 `Singularity-8.8-Release.jar`。
2. 放进 Mindustry 的 `mods` 目录（桌面：`.../Mindustry/mods`；安卓：`.../mindustry/mods`）。
3. **删掉旧的 Singularity JAR** —— 这个模组是替换旧版本的，不能和旧版并装。
4. 需要 **Mindustry v160.5**（见 `mod.hjson` 里的 `minGameVersion`）。

## 从源码构建

```bash
bash tools/setup_env.sh            # 下载 JDK、Mindustry.jar、server jar、R8 和 android.jar
VENDOR=/path/to/vendor bash build.sh
```

产物：`dist/Singularity-8.8-Release.jar`。`build.sh` 先对着 `Mindustry.jar` 编译，
再用 `d8` 生成 `classes.dex`，最后把两者打进同一个 JAR。

### 两台新设备的建模

完成后的机身及建造规划预览全部由程序化三维几何实时绘制，**没有新增机身贴图，也没有远景贴图回退**。炉内转子随炉温旋转；分类器有低速待机旋转、输送加速和配置色标。

模型的占地、投影、转子与壳体间隙均有自动检查。菜单和施工阶段使用引擎通用垃圾桶/筛选标识，它们不是机身贴图。已有设备沿用 8.3 的资源与绘制方式，没有将所有老设备重做一遍。

打开 [离线模型动画预览](docs/v85/models.html)；它不依赖网络。预览来自实际 `draw()` 顶点录制后软件光栅化，**不是游戏实机截图或 FPS 测试**。

### 护盾规则

- 断电或禁用：不拦截弹丸，保留当前护盾；断电时暂停破盾重建。
- 按官方 `BulletType.shieldDamage` 计算损耗，不重复吸收已吸收的弹丸。
- 友军和不可吸收弹丸不会扣盾；接入原版坠毁爆炸护盾接口。
- 极光冷冻液仍为可选强化：扩大半径 8 格，恢复与重建速度 ×1.9；满额供电时重建约 7.38 秒。
- 共振碎片仍提供 22 秒、+5200 容量强化；强化到期后容量与当前值都会限制到基础上限。

## 8.7.7 这次改了什么

**全程爬行，不再有俯冲。** 外缘维持每秒 0.1 格不动——外围接近方式完全不变——但最里一格的封顶从每秒 1 格
降到 **0.4 格**。从此整条吸收剖面（从最外缘一直到视界边缘）是一场连续的慢速爬坡：被捕获的东西即使处于
最快状态，跨过一格也至少需要 2.5 秒。最坏坠心时间不变（290 秒，由外缘速度决定），平均捕获到坠心时间从
72 秒拉长到 130 秒。内容总量冻结（610 / 45 / 110），无头审计全绿，存档往返正常。本版完整说明见
[docs/REPORT-v8.7.7.md](docs/REPORT-v8.7.7.md)，八张中文化学术图表见 [docs/v877/charts](docs/v877/charts)。

## 8.7.6 这次改了什么

**下落更缓。** 8.7.5 的剖面（1 → 3 格/秒）在跨过内圈时仍会猛拽。本次把曲线调向"看得清"而非"吸得狠"：

没有任何东西能越过上限继续加速，而外缘的慢爬移也保证了不会出现"永远吸不进去"的僵死。内容总量再次冻结
（610 / 45 / 110），无头审计全绿重跑：含从外圈拖入并吞没的实机引力探针，以及全部 8.7.x 回归项。

## 安装与升级

1. **先备份游戏存档及战役数据。**
2. 删除/替换旧的 Singularity JAR，只保留 `Singularity-v8.5-beta.jar`。
3. 从 Mindustry 的“模组 → 导入模组”导入 JAR，重启游戏。ZIP 是源码与报告包，不是另一个需要并装的模组。

### 旧存档

- 已用原始 8.3 JAR 实际创建存档，再用 8.4 加载验证。
- 旧战术指挥核心按引擎缺失方块处理变为空地；**不保留占位方块，也不返还建材**。
- 8.3 未破盾的穹顶首次读取时恢复满盾，修复旧版空盾初始化问题；原本正在重建的计时保留。8.4 新存档会精确保留受损护盾值。
- 旧战役在引擎恢复 `SectorInfo` 后补上 Boss 规则。正在防守且进度已经很靠后的地图，会把终局安排到未来；重复加载不叠加 Boss，不重置资源和当前波次，也不重启已占领区域的波次。
- **不会重挖旧存档地形或拆玩家建筑。** 地形拓宽针对新生成地图。旧自然通路过窄时，优先换到安全入口；没有合适入口时，用相近名义生命预算的带额外护盾飞行 Boss，避免地面 Boss 被自然地形困住。
