# 奇点 · Singularity

**工业垃圾测试版** —— 一个面向 [Mindustry](https://github.com/Anuken/Mindustry) v160.5 的大型内容模组，
所有内容集中在一颗星球上：**欧雷利亚**。

这个 jar 里的全部内容（七套合并的内容包、所有方块、单位、物品与流体）都落在欧雷利亚，都进它的科技树，
并且**全部用欧雷利亚资源重新定价**。所有方块与单位模型都是**运行时程序化生成的 3D 模型**：没有手绘机械贴图，
炮塔自由旋转，没有漂浮零件，没有互相穿插的几何体。

* 版本：**8.3-beta**
* 目标游戏：**Mindustry v160.5**（`minGameVersion: 160.5`）
* 桌面端与安卓端**同一个 jar**
* 许可证：**GPL-3.0**（见 `LICENSE`）

## 内容概览

**一颗星球，一棵树。** 欧雷利亚有自己的地形生成器（域扭曲 fBm + 水力侵蚀 + 汇流河网）、32 个自然生成的
战役扇区、自己的矿物、地表、墙体与天气。原版内容在这里被隐藏，模组内容也只在这里出现。

**合并的七套内容：** 奇点主线（黑洞 / 引力子 / 霍金辐射链）、以太泰坦矩阵、欧雷利亚远征、拘留者、
RBMK 白色反应堆、体素工业、体素前哨。合并时**只改配方，不动属性**。

**无传送带物流。** 无人机网络采用 Factorio 式节点角色（主动供给 / 被动供给 / 需求 / 存储 / 缓冲），
按「饥饿度」排序调度，另有无管液体中继、溢流门与反向溢流门、液罐与后勤仓。

### 8.3-beta 新增

| 模块 | 说明 |
|------|------|
| **废料循环** | 工业废料改为**副产物**：淤砂窑、等离子混合器与棱镜压机在正常产出之外各附带掉落 1 份。废料本身毫无价值，必须走完**六台机器的产线**：废料分拣厂（废料→碎屑+渣粉）→ 碎屑熔炉（碎屑→金矿）与矿渣淋洗塔（渣粉+水→流明浆）→ 浆液结晶器（浆→流明矿）→ 共振再合成器（浆+流明矿+金矿→共振碎晶）→ 棱晶再生炉（碎晶+玻璃+浆→棱镜合金）。每一步都有损耗，循环永远跑不过供料工厂。**废料仓**（仅收废料，容量 900）负责缓冲。 |
| **三级核心「堡垒城」** | 6×6，建在堡垒核心之上：更大储量、更高单位上限、重装甲，并派出新的**城塞领航者**——双涵道风扇运载机，机首带切割头，可在欧雷利亚工厂打印。 |
| **核心分级采矿** | 任何核心都不能开采全部矿物等级：流明/堡垒领航者负责地面矿（堡垒采矿最快），城塞领航者是唯一能切割**矿脉墙体**的核心单位，而**所有等级的领航者都无法开采共振碎晶**——它永远需要四级钻机。 |
| **守护穹顶** | 全新 3×3 范围护盾，代码与特效全部自写：`Layer.shields` 上的细双环、缓慢接缝、六边刻度与命中小环——无泛光、不使用原版护盾着色器、无光污染。机制带硬上限：护盾值封顶，耗尽后穹顶**破裂**并停机 14 秒，恢复时为空。极光冷却液可扩大范围并加快重建，共振碎晶可在 22 秒内提升上限。 |
| **地下水井** | 抽水速率提升 2.5 倍（7.00/s → 17.50/s），基础效率 0.4，现在**任何地面**都能抽水，潮湿地面只是更快。 |
| **拘留者面板修复** | 7.4 合并时只导入了 `astro/content` 与 `astro/g3d`，导致驾驶面板、设置页、快捷键、跃迁选点与战术大脑全部失效。现已恢复 `astro/ui`、`astro/ai` 与指挥方块并重新接线。仅修改**名称**：战术指挥核心、拘留者 · 驾驶面板、流明超级工厂——机制完全未动。 |

## 构建

需要 JDK 17、Mindustry jar 与安卓平台 jar（安装脚本会自动下载）。

```bash
bash tools/setup_env.sh     # 下载 Mindustry.jar、server-release.jar、r8.jar、android.jar、JDK 17
chmod +x *.sh
./build.sh                  # 烘焙 3D 模型、编译、dex，产出 dist/Singularity-v8.3-beta.jar
```

测试套件（全部跑官方无头服务器）：

```bash
./cmdtest.sh      # v8.2：装载方案、可操控无人机、守恒、投影仪、泰坦
./logitest.sh     # v8.1：物流网络、液体、闸门
./test_server.sh  # 全量内容 / 战役 / 平衡审计
./maptest.sh      # 战役地形
./diag.sh         # 快速冒烟测试
```

## 安装

把 `Singularity-v8.3-beta.jar` 放进 `Mindustry/mods/`（桌面），或在安卓端用模组界面的「导入文件」导入。
两端是同一个 jar。
